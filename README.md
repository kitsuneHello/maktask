# MakTask

**MakTask** は、プロジェクトとタスクを管理するためのWindows用タスク管理アプリケーションです。

## ✨ 機能

- 📁 **プロジェクト管理** - 複数のプロジェクトを作成し、テーマカラーで区別
- ✅ **タスク管理** - タスクの作成、編集、削除、サブタスク対応
- 📅 **カレンダービュー** - 月間カレンダーでタスクを視覚的に確認
- 📊 **ガントチャート** - タスクのスケジュールをガントチャートで表示
- 📋 **リストビュー** - プロジェクトごとにタスクを一覧表示
- 📝 **進捗記録** - タスクごとに進捗ログを記録
- 🎯 **期限モード** - 締め切り日を設定可能
- ⏰ **時刻指定** - 終日タスクまたは時刻指定タスクに対応

## 🚀 インストール方法

### 方法1: リリースからダウンロード（推奨）

1. [Releases](../../releases) ページにアクセス
2. 最新リリースの `MakTask_x.x.x_x64.msix` をダウンロード
3. ダウンロードしたファイルをダブルクリックしてインストール

> **注意**: 初回インストール時は、証明書を信頼する必要がある場合があります。

### 方法2: ソースからビルド

#### 必要な環境
- Windows 10 version 1809 以降
- Visual Studio 2022
- .NET 8.0 SDK
- Windows App SDK

#### ビルド手順
```bash
git clone https://github.com/kitsuneHello/maktask.git
cd maktask
```

1. Visual Studio 2022 で `maktask.sln` を開く
2. ソリューション構成を `Debug` または `Release` に設定
3. `ビルド` → `ソリューションのビルド`
4. `デバッグ` → `デバッグの開始` または F5

## 📖 使い方

### プロジェクトを作成する

1. 左サイドバーの下部にある **「＋ プロジェクト作成」** ボタンをクリック
2. プロジェクト名を入力
3. テーマカラーを選択
4. **「作成」** ボタンをクリック

### タスクを作成する

1. **「タスク作成」** ボタンをクリック、またはカレンダーを右クリック
2. プロジェクトを選択
3. タスク名を入力
4. 期間を設定
   - **終日**: ONの場合は日付のみ、OFFの場合は時刻も指定
   - **期限モード**: ONにすると開始日なしの締め切りタスクになります
5. 必要に応じてサブタスクを追加
6. **「作成」** ボタンをクリック

### カレンダーの操作

- **左右ボタン**: 前月/翌月に移動
- **「今日」ボタン**: 今日の日付に移動
- **タスクバーをクリック**: タスク詳細を開く
- **右クリック**: その日のタスク一覧を表示、新規タスク作成

### ビューの切り替え

上部のボタンで3つのビューを切り替えられます：

| ビュー | 説明 |
|--------|------|
| カレンダー | 月間カレンダー形式でタスクを表示 |
| ガントチャート | タスクのスケジュールをガントチャートで表示 |
| リスト | プロジェクトごとにタスクを一覧表示 |

### プロジェクトの表示/非表示

左サイドバーのプロジェクト名の横にあるトグルスイッチで、ホームビューに表示するプロジェクトを選択できます。

### タスクの編集

1. タスクをクリックしてタスク詳細を開く
2. **「編集」** ボタンをクリック
3. 内容を変更
4. **「保存」** ボタンをクリック

### 進捗を記録する

1. タスク詳細ページを開く
2. 「進捗記録」セクションでタイトルと内容を入力
3. **「記録」** ボタンをクリック

記録した日付は進捗カレンダーに緑色で表示されます。

## 🗂️ データ保存場所

アプリのデータは以下の場所に保存されます：
```
%LOCALAPPDATA%\maktask\maktask_data.json
```
